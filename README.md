# Iniciando com Godot

Projeto de introdução ao desenvolvimento de jogos utilizando a engine Godot, com foco no aprendizado dos conceitos iniciais de criação de jogos e programação com GDScript.

## Tecnologias e Ferramentas

* Godot
* GDScript
* Desenvolvimento de Jogos

## Funcionalidades

* Primeiros testes com Godot
* Estrutura inicial de projeto
* Prática com GDScript
* Conceitos básicos de game development

## Objetivo

O objetivo do projeto é praticar os primeiros conceitos de desenvolvimento de jogos utilizando Godot e entender a estrutura básica de projetos dentro da engine.
